# naimxofficial

> Personal portfolio of **Md. Naim Uddin** — MERN-Stack Developer.

A modern, responsive portfolio showcasing projects, skills, and experience. Built with Next.js, featuring smooth animations, dark/light mode, and a clean Nebula-inspired design system.

**Live Site:** [https://naimxofficial.vercel.app](https://naimxofficial.vercel.app) or  [https://naimxofficial.netlify.app/](https://naimxofficial.netlify.app/)

---

## Overview

This portfolio is designed to present my work as a MERN-stack developer with a focus on modern web technologies. It includes sections for about, skills, services, projects, education, blog, and contact — all wrapped in a consistent visual language with smooth motion and theme support.

---

## Features

| Feature | Description |
|---------|-------------|
| **Responsive Design** | Fully optimized for mobile, tablet, and desktop |
| **Dark / Light Mode** | Theme toggle with system preference support via `next-themes` |
| **Smooth Animations** | Section transitions and micro-interactions powered by Motion |
| **Particle Background** | Interactive WebGL particle field on the hero section |
| **Smooth Scrolling** | Enhanced scroll experience using Lenis |
| **Custom 404 Page** | Branded not-found page with navigation back to home |
| **Contact Form** | Functional contact section with email support (Nodemailer) |
| **SEO Friendly** | Proper metadata and semantic structure |
| **Performance Focused** | Optimized images, code splitting, and modern Next.js features |

---

## Sections

| Section | Description |
|---------|-------------|
| **Hero** | Introduction with typing effect, profile image, and CTAs |
| **About** | Background, focus areas, and key highlights |
| **Skills** | Technology stack presented in an animated marquee |
| **Services** | What I offer — full-stack development, APIs, auth, UI, etc. |
| **Projects** | Selected work with live links and source code |
| **Education** | Academic background and relevant experience |
| **Blog** | Notes and insights (placeholder-ready for future posts) |
| **Contact** | Get in touch form and social links |
| **Footer** | Navigation, socials, and credits |

## Tech Stack

| Category | Technologies |
|----------|--------------|
| **Framework** | Next.js 16, React 19 |
| **Styling** | Tailwind CSS 4, HeroUI 3 |
| **Animation** | Motion (Framer Motion), GSAP |
| **3D / Effects** | Three.js (particle field) |
| **Scrolling** | Lenis |
| **Icons** | Lucide React, React Icons |
| **Theming** | next-themes |
| **Email** | Nodemailer |
| **Language** | JavaScript |
